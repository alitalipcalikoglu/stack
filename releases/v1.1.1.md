# atc-web production suite 1.1.1

Release date: 2026-09-22

This immutable patch release closes the Console full-stack SvelteKit migration and its final M10
production audit. It replaces the historical Console runtime with the canonical adapter-node
application, preserves all 156 Console API operations and 34 frontend route patterns, includes the
tracked Geo country dataset, and keeps the existing distribution, generated-client, OpenAPI, and
MCP product boundaries.

## Version identities

- Stack and the 13 application repositories: `v1.1.1`.
- Shared `service-core`: unchanged at its independent `v1.12.0` release.
- Historical `v1.0.0` and `v1.1.0` suite tags and `service-core` release tags remain immutable.

The authoritative installer descriptor is
[`../installation-manifests/v1.1.1.json`](../installation-manifests/v1.1.1.json). It binds every
managed official repository to an immutable annotated tag and peeled commit. The default release
is selected by
[`../installation-manifests/supported.json`](../installation-manifests/supported.json).

## Console migration closure

- Console is one SSR-enabled SvelteKit 2 application on adapter-node, served by `server.mjs`.
- Filesystem routes own the backend APIs and frontend. The Fastify application, custom routers,
  legacy `ui/` SPA, SPA shell/fallback, and selectable legacy runtime are absent.
- Production Docker, direct Node, PM2, Stack setup/up/down/status, admin CLI, streaming, browser,
  authentication, security-header, CSRF, trust-proxy, PWA, theme, i18n, toast, and offline gates
  passed.
- The canonical contract remains 122 paths / 156 Console operations; the suite remains 376
  operations.

## Release validation

- Console passed 131/131 tests, typecheck with zero errors and warnings, and its production build.
- Stack passed 92/92 tests with integration enabled and zero skips. The other repositories retained
  their recorded full-suite passes, including `service-core` 98/98 and Geo 44/44.
- Generated TypeScript clients cover 13/13 services and 376/376 operations, with drift,
  typechecking, and 6/6 tests passing.
- MCP remains STDIO-only with a 376-operation catalog, explicit 10-tool allowlist, and 17/17 tests.
- Production dependency audits reported zero vulnerabilities. The three accepted low-severity
  advisories are development-only.
- Pre-publication installation from official `main` cloned all 14 managed repositories, matched
  every candidate manifest SHA, completed 14 deterministic `npm ci` installs and setup, built
  Console, reached 13/13 PM2 readiness, passed representative authenticated Console/docs/downstream
  integration, reused 14/14 repositories on rerun, and shut down cleanly.
- Docker host publication was revalidated with the intended non-loopback bind. The earlier reset
  was caused by injecting Stack's local-only `HOST=127.0.0.1` setting into a container; the
  canonical image default `0.0.0.0` is reachable through its published IPv4 and IPv6 host ports.

## Accepted non-blocking debt

- The locally bundled, lazy-loaded Swagger UI chunk emits a build-size advisory.
- Existing frozen Range behavior and conservative PWA/cache behavior remain intentional.
- MCP expansion remains cancelled; no new transport, tool, authentication mode, or package
  publication is included.

Exact immutable tag identities and authoritative post-publication default-install evidence are
recorded in `v1.1.1.json` on `main` after the Stack tag is cut. No GitHub Release object or
GitHub Actions workflow is part of this release policy.
