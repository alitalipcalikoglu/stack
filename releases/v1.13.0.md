# atc-web production suite 1.13.0

Release date: 2026-10-06

This immutable release supersedes `v1.1.3` as the supported default installation. It unifies
versioning: all 15 repositories, including `service-core`, now carry the same version, `1.13.0`.
The number is above both previous lines (`1.1.3` for the suite, `1.12.1` for `service-core`), so no
repository moves backwards.

## Version identities

- Stack, the 13 application repositories, and `service-core`: `v1.13.0`.
- Historical suite tags `v1.0.0` to `v1.1.3` and `service-core` tags `v1.11.1` to `v1.12.1` remain
  immutable and unchanged.

The authoritative installer descriptor is
[`../installation-manifests/v1.13.0.json`](../installation-manifests/v1.13.0.json). The default
release is selected by
[`../installation-manifests/supported.json`](../installation-manifests/supported.json).

## Changes since 1.1.3

- **Auth enumeration resistance:** `POST /v1/auth/verify-email/resend` and
  `POST /v1/auth/password/forgot` always return `202` for a valid request. Unknown, already-verified,
  disabled, and cooldown cases are silent no-ops, so neither status nor error code reveals whether
  an account exists. The `ALREADY_VERIFIED` and `TOO_MANY_REQUESTS` error codes no longer exist; the
  per-API-key `429 RATE_LIMITED` still applies. Callers that showed a "already verified" or "wait
  before retrying" message from those codes must drop that branch.
- No dependency versions changed. `service-core` `1.13.0` has no code change over `1.12.1`.
